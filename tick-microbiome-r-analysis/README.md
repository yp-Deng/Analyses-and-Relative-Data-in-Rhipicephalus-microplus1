R 分析代码、轻量输入表和结果图件。已排除 R 工作区、日志、基因组 FASTA 及超过 10 MiB 的大型输入或中间文件。

## GitHub 上传说明

- 已保留 571 个文件（共 443.19 MiB）。
- MANIFEST.tsv 列出已包含文件；EXCLUDED_FILES.tsv 列出未包含的源文件及字节数。
- .gitignore 阻止常见工作区文件、日志及大规模分析中间产物被误提交。
- 如需发布被排除的大型原始数据，请使用 Zenodo、Figshare、OSF 或 Git LFS，并在此仓库 README 中补充 DOI/下载链接。
